# 金融世界模型

一套从市场微观结构逐层扩展到宏观、跨境传导、叙事与复杂系统研究的中文金融课程网站。课程正文按“研究、写作、两名独立审稿人复核、校订与交付验收”的流程逐节发布。

## 本地运行

需要 Node.js 22 或更高版本及 pnpm：

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:3000/`。

## GitHub Pages

推送到 `main` 后，`.github/workflows/deploy-pages.yml` 会自动完成静态导出并发布 GitHub Pages。GitHub Pages 构建只在 CI 中启用；本地 Vinext 开发与生产预览配置保持不变。

## 内容边界

网页中的合成实验用于说明机制、口径和边界，不自动构成现实数据、PIT、因果识别、预测表现、交易绩效或生产资格。每节页面会单独说明当前审稿与证据状态。
